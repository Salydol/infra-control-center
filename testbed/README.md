# Стенд

Три ВМ с Docker, демо-приложение из 6–8 сервисов, генератор нагрузки (k6)
и инжектор сбоев шести классов.

| ВМ | Роль | Ресурсы (минимум) |
|---|---|---|
| `icc-node1` | API, очередь | 2 vCPU, 2 ГБ RAM, 20 ГБ диск |
| `icc-node2` | Воркеры, Redis | 2 vCPU, 2 ГБ RAM, 20 ГБ диск |
| `icc-node3` | PostgreSQL, генератор нагрузки | 2 vCPU, 2 ГБ RAM, 20 ГБ диск |

ОС — Ubuntu Server 24.04 LTS. Подготовка каждой ВМ:

```bash
sudo bash setup-node.sh icc-node1
```

Структура (заполняется на неделях 2–3):

- `vm/` — подготовка узлов
- `app/` — демо-приложение и его compose-файлы
- `load/` — сценарии k6
- `faults/` — инжектор сбоев и разметка инцидентов

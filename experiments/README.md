# Эксперименты

Сравнение методов поиска первопричины (раздел 3 ТЗ): M против B1–B3, абляция,
проверка на RCAEval (RE2, RE3), оценка LLM-объяснений.

Правила воспроизводимости: фиксированные random seed, зафиксированные версии
зависимостей, сырые данные не хранятся в git (`data/raw/`), каждый прогон
пишет результаты в отдельную папку с конфигурацией запуска.
